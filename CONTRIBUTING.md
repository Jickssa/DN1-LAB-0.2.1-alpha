# Contributing / Contribuer

## Français
1. Discussions pour les concepts ; Issues pour tâches et bugs reproductibles.
2. Décrire environnement, version OS, étapes, résultat attendu et constaté.
3. En DSP, donner plages, bornes numériques, hypothèses fréquence/bloc et tests.
4. Pour une machine, inclure manifeste, ID demandé, cibles, API, dépendances, licence et ressources.
5. Ne jamais annoncer de compatibilité matérielle sans test matériel correspondant.
6. Documenter en FR/EN, ou ouvrir une tâche de traduction.
Pull requests : motivation, résumé, commandes exactes de test, résultats, limites, risques et preuves. Ne pas inclure de firmware propriétaire ni de secrets.

## English
1. Use Discussions for concepts; Issues for tasks and reproducible bugs.
2. State environment, OS version, steps, expected behavior and observed result.
3. For DSP, provide parameter ranges, numeric bounds, sample-rate/block assumptions and tests.
4. For a machine, include manifest, requested ID, targets, API, dependencies, license and resource estimates.
5. Never claim hardware compatibility without the corresponding hardware test.
6. Document in French and English, or open a translation task.
Pull requests must include motivation, summary, exact test commands, results, limitations, risks and evidence. Do not include proprietary firmware or secrets.
