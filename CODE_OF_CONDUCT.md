# Code of Conduct / Code de conduite

## Français
Les échanges doivent rester respectueux, précis et centrés sur le travail. Harcèlement, insultes ciblées, discrimination, intimidation, divulgation de données personnelles et attaques personnelles répétées sont exclus. Les désaccords techniques sont bienvenus lorsqu'ils reposent sur des arguments, mesures et sources. Les mainteneurs peuvent modérer les échanges contraires à ces règles.

## English
Interactions must remain respectful, precise and work-focused. Harassment, targeted insults, discrimination, intimidation, doxxing and repeated personal attacks are unacceptable. Technical disagreement is welcome when based on reasoning, measurements and sources. Maintainers may moderate interactions that violate these rules.
