# Source provenance / Provenance des sources

## Imported release

This source tree is based on the DN1-LAB 0.2.2-alpha archive prepared on 17 November 2026:

- Archive: `DN1-LAB-0.2.2-alpha.zip`
- SHA-256: `77d467e7a85295880deed7df5016c2026c65a9e5d17a5d297c6439475b4a5f42`
- Original per-file checksum list: `source-provenance/DN1-LAB-0.2.2-alpha-SHA256SUMS-original.txt`

The original checksum list is retained for provenance. `SHA256SUMS.txt` in this repository is regenerated for the actual imported file set.

## Import adjustments

- The technical README from the source archive is preserved as `docs/TECHNICAL-OVERVIEW.md`; this repository's root README is the bilingual community entry point.
- The generated Linux host executables are deliberately excluded; they are reproducible test outputs, not source artifacts.
- Three 48 kHz mono alpha WAV demos are represented as Vorbis OGG previews to reduce repository weight. The source WAV files remain available in the original archive and their original hashes are retained in the archived checksum list.
- Legacy `audio/*.wav` test renders are generated by test runners and are not committed.
- Catalogue manifests, validation tooling, GitHub Actions workflows and static Workbench pages are additions to this repository.

The firmware source image is not included. The OS 1.44 hash and structural fingerprint in the technical documentation describe the locally verified source input; they do not grant redistribution rights.
