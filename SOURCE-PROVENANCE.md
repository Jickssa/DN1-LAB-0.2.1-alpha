# Source provenance / Provenance des sources

## Imported DN1-LAB source release

The SDK-alpha machine sources and documentation are based on the DN1-LAB 0.2.2-alpha source package prepared on 17 November 2026:

- Original archive: `DN1-LAB-0.2.2-alpha.zip`
- SHA-256: `77d467e7a85295880deed7df5016c2026c65a9e5d17a5d297c6439475b4a5f42`

## Import notes

- The three shared SDK-alpha engines are directly browsable in `sdk-alpha/`.
- The complete working package also contains the legacy API, host test harness, build scripts, test suites, docs and demo renders. Those files have not yet been imported individually into this GitHub repository.
- Generated host executables and WAV renders are excluded from the GitHub source tree.
- The Workbench and static site are additional repository components.
- The stock OS 1.44 firmware image is not included. Structural fingerprints and hashes in `docs/VALIDATION.md` identify the local analysis input but do not grant redistribution rights.

The complete package is retained as a separate working artifact. Do not infer that every file from the package is present in this repository.
