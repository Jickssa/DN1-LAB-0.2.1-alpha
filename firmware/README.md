# Firmware workspace / Espace firmware

Firmware images are local user inputs and should not be committed unless redistribution is explicitly lawful and documented. Never commit proprietary firmware, extracted copyrighted sections or personal backups.

Les images firmware sont des entrées locales fournies par l'utilisateur et ne doivent pas être publiées sauf redistribution explicitement légale et documentée. Ne jamais committer un firmware propriétaire, des sections protégées extraites ou des sauvegardes personnelles.
