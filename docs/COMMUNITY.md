# Community / Communauté

## Français
Contributions ouvertes en français et en anglais. Utiliser Discussions pour les orientations et idées, Issues pour les tâches et défauts reproductibles, Pull Requests pour le code, la documentation, les tests, traductions et presets.

Une proposition de machine doit inclure : objectif sonore, différences par rapport aux machines du catalogue, paramètres, OS/SDK, API requise, coût CPU/mémoire estimé, licence, dépendances, provenance, tests et niveau de maturité.

Axes : synthèse/DSP, outils SDK, documentation, UX, reproductibilité, presets et démos audio. Les affirmations d'innovation absolue exigent une recherche d'antériorité ; le projet ne présume pas qu'une idée est sans précédent.

## English
Contributions in French and English are welcome. Use Discussions for direction and ideas, Issues for tasks and reproducible defects, Pull Requests for code, documentation, tests, translations and presets.

A machine proposal must include: sonic goal, differences from catalogue entries, controls, OS/SDK, required API, estimated CPU/memory, license, dependencies, provenance, tests and maturity level.

Tracks: synthesis/DSP, SDK tooling, documentation, UX, reproducibility, presets and audio demos. Absolute novelty claims require prior-art research; the project does not assume a concept is unprecedented.
