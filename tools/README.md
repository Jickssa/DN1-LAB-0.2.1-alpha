# Tooling / Outils

Reserved for reviewed and validated tooling. Firmware parsers, patchers and flash utilities must include format tests, malformed-input handling, reproducibility evidence and safety documentation before being placed here.

Réservé aux outils relus et validés. Les parseurs, patchers et utilitaires de flash doivent inclure des tests de format, une gestion des entrées malformées, des preuves de reproductibilité et une documentation de sûreté avant leur ajout.
